# RentPilot AI — Project Charter

Проект: RentPilot AI.

Цель: сначала создать личный AI-помощник для поиска
аренды жилья в Польше. После создания работающего,
протестированного и документированного проекта
подготовить его к публичному использованию.

Будущий рынок: Европа.
Первый интерфейс: Telegram.
Будущий интерфейс: веб-сайт.

Команда:
- Пользователь — Founder / Product Owner.
- ChatGPT — CTO, архитектор, автор технических заданий
  и промтов, контролёр архитектуры.
- Claude Code — основной разработчик.
- OpenAI Codex — независимый проверяющий и помощник
  в чтении и понимании кода.

Главный принцип:
не допускать неконтролируемых архитектурных изменений.
Все задачи имеют критерии приёмки, тесты и проверку.

Пользователь начинающий разработчик.
Всю работу необходимо объяснять доступным языком.
Код должен быть понятным и пригодным для демонстрации
работодателю.

Сначала личный продукт, затем портфолио,
затем публичная версия.
