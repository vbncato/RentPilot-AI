## Start here
1. Read `docs/PROJECT_CHARTER.md`.
2. Read `AGENTS.md` (Codex) and `CLAUDE.md` (Claude Code).

## Repository principles
- Personal version first; portfolio-ready project second; public product later.
- No unapproved architectural changes.
- Small tasks, acceptance criteria, tests, independent review.
- Never commit secrets or private session files.

## Planned directories
- `docs/`: requirements, architecture, security, and decision records.
